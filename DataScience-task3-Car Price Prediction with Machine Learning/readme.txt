# Used Car Price Prediction Using Machine Learning

## Project Overview
This project predicts the selling price of used cars using machine learning techniques. It uses vehicle information such as manufacturing year, kilometres driven, fuel type, transmission, mileage, engine capacity and other features.

## Objective
To develop a machine learning model that estimates the selling price of a used car based on its characteristics.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Google Colab

## Dataset
Vehicle Dataset from CarDekho (Car Details V3).

## Project Workflow
1. Dataset collection
2. Data loading and inspection
3. Data cleaning
4. Exploratory Data Analysis (EDA)
5. Feature engineering
6. Categorical data encoding
7. Training and testing data splitting
8. Linear Regression model
9. Random Forest Regression model
10. Model evaluation and comparison
11. Feature importance visualization
12. Model saving using Joblib

## Machine Learning Models
- Linear Regression
- Random Forest Regressor

## Evaluation Metrics
- Mean Absolute Error (MAE)
- Root Mean Squared Error (RMSE)
- R² Score
