## Objective
To analyze unemployment trends in India using Python. This project studies unemployment rates across different regions, monthly trends, employment indicators, and the changes in unemployment before and during the COVID-19 period.

## Dataset
Unemployment in India – Kaggle

## Technologies Used
- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Project Workflow
1. Dataset loading and inspection.
2. Data cleaning and preprocessing.
3. Exploratory Data Analysis (EDA).
4. Region-wise unemployment analysis.
5. Monthly unemployment trend visualization.
6. Comparison of unemployment across regions.
7. Correlation heatmap.
8. Pre-COVID and during-COVID comparison.

## Project Files
- `Unemployment_Analysis.ipynb` – Complete Python notebook.
- `screenshots/` – Project visualization screenshots.

## Conclusion
This project helped me understand unemployment patterns in India through data analysis and visualization. It provided practical experience in Python, data cleaning, exploratory data analysis, and graphical representation of data.
